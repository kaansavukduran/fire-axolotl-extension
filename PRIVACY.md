# Gizlilik / Privacy

Bu eklenti hesap, telemetri veya kendi analiz hizmetini eklemez. Firefox'un kendi ağ hizmetleri ve tercihleri Firefox tarafından yönetilir. / No added account, telemetry or analytics service; native Firefox services remain under Firefox control.

- Aion ayarları, kelimeler, çeviri taslağı, oyun rekoru ve karakterler yereldir. Otomatik bulut aktarımı yoktur. Açıkça etkinleştirilen storage.sync düğmeleri yalnızca izin verilen tercih alanlarını Firefox Sync’e aktarır; kelime ve taslaklar bu aktarımın dışındadır. / Aion settings, words, draft, scores and characters are local, without automatic cloud sync.
- uBO filtre listesini günceller; upstream filtre barındırıcılarına ağ bağlantıları yapar. Gelişmiş panelden listeler ve güncelleme ayarları yönetilir. / uBO fetches filter updates from upstream hosts; control these in its dashboard.
- Yerel Qwen ve M2M100 için çalışma kodu ve WASM dosyaları pakettedir. Seçilen modelin verisi açık indirme eyleminde sabitlenmiş Hugging Face sürümünden/CDN’den alınır veya kullanıcı yerel dosya seçer. SHA-256 doğrulanır. Çıkarım ağ isteği yapamaz; metin ve komut modele bu cihazda verilir. Model önbelleğini silmek diğer Aion verilerini silmez. / Model data downloads only on explicit action; inference is local and network access is blocked.
- Çeviri, ayarlarda kendin kaydettiğin LibreTranslate uyumlu HTTPS hizmetine yalnızca **Çevir** eylemiyle metin gönderir. API anahtarı gerektiren hizmetler desteklenmez. Yönlendirmeler reddedilir; 20 saniyede zaman aşımı olur. / Translation sends text only on explicit action to your chosen endpoint, without credentials or redirects.
- Görselle arama, seçtiğin sağlayıcıyı görselin URL'siyle yeni sekmede açar. O sağlayıcı görüntü URL'sini ve web bağlantısına ait olağan bilgileri alır. / Image search shares the URL with the explicitly selected provider.
- Yeni sekme araması Firefox'un seçili motoruna sorguyu gönderir. QR ve oyun yereldir. / New-tab search uses the selected Firefox search engine; QR and gameplay are local.
- İsteğe bağlı sayfa koyulaştırma, seçili ana belgeye yerel Dark Reader kodu yükler. Haricî görsel analizi için fetch kapalıdır; normal sayfanın kendi ağ trafiği devam eder. / Optional page darkening uses bundled code with remote analysis fetching disabled; ordinary page traffic continues.
- **Güncellemeleri kontrol et** yalnızca basıldığında bu deponun GitHub Release API'sine bağlanır. / Manual update checks contact this repository's GitHub Releases API.

## İzinler / Permissions

uBO'nun gerçek ağ/kozmetik filtrelemesi `<all_urls>`, `webRequest`, `webRequestBlocking`, `webNavigation`, `dns`, `privacy`, `publicSuffix`, `alarms`, `unlimitedStorage`, `tabs` ve `storage` gerektirir. Konteynerler için `contextualIdentities` ve `cookies`, sağ tık için `menus`, renk teması için `theme`, Firefox varsayılan araması için `search` kullanılır. `activeTab` donör akışlarıyla birlikte korunur.

The manifest declares website content, website activity and search terms because the explicitly invoked translation, image-search and search tools can send those types to a selected service. This does not enable background collection or telemetry.

All-site access is required at installation by the integrated blocker. Choosing a translation endpoint is consent in the extension's own UI, **not a separate host-permission boundary**. Page content cannot invoke privileged Aion commands: the background checks both sender extension ID and the exact allowed packaged page URL. No native-messaging host or local executable is required. Firefox-protected pages remain protected.

Yedek JSON'ları kelimeler ve hizmet adresini içerebilir. Özel karakter yedeği görüntüyü içerir. İçe aktarma ağ izni veya yeni bir güvenilir çeviri adresi vermez. Geçici konteyner temizliği Firefox geçmişini/indirmelerini silmez. / Backups may contain private data; imports retain the currently trusted endpoint. Container cleanup does not erase history/downloads.

Site renk/font ve hız kuralları, yalnızca kullanıcı Hatırla seçtiğinde en fazla 200 origin olarak bu cihazda saklanır; ziyaret geçmişi veya zaman çizelgesi kaydedilmez. Açık sekme başlık/adresleri araçların çalışması için geçici olarak okunur. Yerel JSON yedeği site kurallarını ve taslağı da içerebilir; model ve karakter PNG’leri ayrı tutulur.

Bergamot/M2M100 ile otomatik kaynak dili seçildiğinde önce altyazının dil bilgisi, yoksa Firefox’un dil algılama API’si kullanılır. Yerel Firefox testinde algılama ağ kapalıyken çalıştı. Güvenilir sonuç yoksa kullanıcı kaynak dili seçer.

Sekme geri açma (0.5.0): `sessions` isteğe bağlı izindir; zorunlu kurulum izinlerine eklenmez. Yalnız geri aç düğmesi Firefox izin penceresini tetikler. İzin verildikten sonra en fazla 10 son kapanan kaydı taranarak bir sekme geri açılır; liste yalnız işlem sırasında bellekte kullanılır, eklenti depolamasına, ayar yedeğine, Sync’e veya sunucuya yazılmaz. Kullanıcı yan panelden bu izni kaldırabilir. Seçili sekmeler listesi de yalnız sayfa belleğindedir. Firefox’un kendi oturum verisi kendi yönetimindedir. Geçici konteyner temizliği veya silinmiş site verisi geri açma ile geri getirileceği anlamına gelmez.

Sayfa/diyalog çevirisi (0.6.0): metin yalnız açık **Metni oku ve önizle** eyleminde seçili ana belgeden okunur. En fazla 40 metin parçası ve 12.000 karakter, belgeye ait geçici düğüm referanslarıyla bellekte tutulur; çeviri panelinde önizlenir. Uygula düğmesi bu metni seçili yerel modele verir. Bu tarama/sonuçlar eklenti depolamasına, JSON yedeğine, Sync’e veya çeviri sunucusuna yazılmaz. Yeni tarama veya geri alma, geçici haritayı temizler; sayfa yenilenince belgeye ait durum kaybolur. Form alanları, düzenlenebilir alanlar, kod, gizli metin ve iframe’ler okunmaz. Normal sayfanın kendi scriptleri görüntülenen özgün veya çevrilmiş metni okuyabilir; eklenti sitenin kendi davranışını engellediğini iddia etmez. / Explicit preview and local application only; the transient DOM snapshot is never persisted or synced. The website can see text displayed in its own document.

Altyazıyla öğrenme (0.7.0): kaynak listesi açık yenile eylemiyle oynatıcının TextTrack ad/dil bilgilerini ve o belgeye yüklenmiş özgün altyazı varlığını okur. Satır döngüsü yalnız yerel medya zamanı ve olaylarıyla çalışır; yeni ağ bağlantısı veya izin eklemez. Döngü/ham dosya satırları Sync’e veya eklenti depolamasına yazılmaz; kelime kaydı ayrı açık kaydetme eylemidir. Panel kapanınca döngü ve katman temizlenir, oynatıcı altyazısı geri gelir. / Caption learning reads local player/imported sources explicitly and adds no network call or permission. Loop state and raw file cues are not persisted or synced.

Bergamot paket içi çeviri (0.8.0): EN↔TR motoru/WASM ve yaklaşık 43,8 MB model verisi XPI içinde gelir. İlk açık yerel çeviri eylemi motoru başlatabilir; model indirme, hesap veya bulut çağrısı yapılmaz. Kaynaklar yalnız kendi eklenti URI’lerinden ana bağlamda okunur, worker’a aktarılır ve hash’leri doğrulanır. Worker çıkarımı yalnız aktarılmış doğrulanmış baytları kullanır; gerçek fetch/ağ erişimi yoktur. Metinler model önbelleğine veya Sync’e yazılmaz; ayrıca açıkça kaydedilen taslak/kelime davranışları önceki gibidir. / The shipped EN↔TR model supports offline first use. Inference has no network route, and no translation server is contacted.

Altyazı kelime kartı (0.9.0): yalnız açık Aion katmanının kaynak kelimeleri, kullanıcının gerçek düğme/klavye eyleminden sonra yerel modele verilir veya mevcut yerel kelime defterine yazılır. Kart açılması/seçim model başlatmaz. Arka plan yetkisi rastgele token, sekme, belge URL’si ve frame ile sınırlıdır; yeni gezinmede/katman kapanınca iptal edilir. Kart üzerinden ayar okuma, genel AI görevi, keyfi metin, harici çeviri veya model indirme yolu yoktur. Kart seçimleri/yanıtları otomatik saklanmaz; yalnız açık kaydetme kaynak metnini kelime defterine ekler. Genel AI/araç mesajları hâlâ yalnız eklenti sayfalarına açıktır. / The on-video card only translates authorized subtitle terms locally after an explicit action; saving is separate and writes the source term to the existing local vocabulary.

Kelime defteri (0.10.0): mevcut profil içi `settings.vocabulary` dizisi kullanılır, veri biçimi değiştirilmez. Arama/sayfalama cihazda yapılır; veri yönetimi AI motorunu başlatmaz. Açık dışa aktarma yalnız format/sürüm/kelime metinlerini yerel JSON dosyasına koyar; taslak, endpoint ve görünüm ayarı eklemez. İçe aktarma 12 MiB/5.000 kayıt/300 karakter sınırlarını denetler, önizleme yazmaz, açık birleştirme mevcut kayıtları korur. Silinen metin için en son 20 geri alma kaydı yalnız arka plan belleğinde tutulur; yeniden başlatmada kaybolur. Sayfada yalnız son silmenin düğmesi sunulur; yeni silme veya sayfa kapanışı önceki düğmenin erişimini bırakır. Kelime defteri komutları yalnız izin verilen eklenti sayfalarına açıktır; video kartının yetkileri silme/içe aktarma/geri alma erişimi vermez. / Vocabulary management and search stay local, never load AI and never sync automatically. Word-only JSON export excludes settings, endpoints and drafts.
