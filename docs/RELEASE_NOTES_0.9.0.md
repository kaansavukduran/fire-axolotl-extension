# Fire Axolotl Extension 0.9.0 · video üzerinde öğrenme

Altyazının **Bu satırdan öğren** düğmesi videoyu durdurur; kelime veya cümle seçip yerelde çevirebilir, kaynak kelimeyi deftere kaydedebilir ve açık düğmeyle devam edebilirsin. Kartı açmak ya da kelime seçmek model başlatmaz. Canlı altyazı güncellenirken kart korunur. Escape duraklatılmış bırakır.

Paket içi EN↔TR Bergamot ilk kullanımda bile çevrimdışı çalışır. Erişilebilir iframe, TR/EN kart ve HTML oynatıcı tam ekranı desteklenir; native video tam ekranında yalnız altyazı görünür. Her servisin özel altyazısına erişim veya çeviri kalitesi garantisi yoktur. Qwen’in Türkçe çeviri sorunu ve deyim hataları sürer; Qwen/M2M100 ağırlıkları ayrıca alınır.

Yeni izin istenmez. Kartın yerel çeviri/kaydı yalnız açık katmandaki kaynak metne, ilgili sekme/frame/URL ve geçici token’a bağlıdır. Genel AI, ayarlar, keyfi ağ veya model indirme erişimi vermez.

**İmzasız geliştirici önizlemesi.** İki alternatif XPI’den yalnız birini kur. `native-newtab` mevcut Firefox yeni sekmesini korur. `about:debugging#/runtime/this-firefox` → Geçici Eklenti Yükle. Kalıcı kurulum/otomatik güncelleme Mozilla imzasını bekliyor.
