Fire Axolotl Extension · Firefox geliştirici önizlemesi

TÜRKÇE
1. Bu ZIP'i bilgisayarında bir klasöre çıkar.
2. Firefox adres çubuğuna about:debugging#/runtime/this-firefox yazıp Enter'a bas.
3. Geçici Eklenti Yükle'ye bas ve bu klasördeki .xpi dosyasını seç.
4. Listede Fire Axolotl Extension görünür. Araç çubuğundaki Aion simgesini veya
   yapboz menüsündeki Fire Axolotl Extension öğesini aç.
   Güncelleme sonrası açık YouTube sayfasını yenile.

Aynı kimlikli eski önizlemeyi önce silme. Yeni XPI'yi geçici eklenti yükleme
menüsünden seçerek güncelle; ayarların korunur. Bu paket Firefox'un mevcut yeni
sekmesini korur. Aion oyunu menüden ayrıca açılabilir.

Bu önizleme Mozilla tarafından imzalanmış kalıcı bir sürüm değildir. Firefox'u
yeniden başlatınca tekrar yüklemen gerekir. İmza, TLS veya sandbox denetimlerini
kapatma. Normal kalıcı kurulum, ayrı Mozilla imzasını bekler.

Video: kurulumdan sonra videoyu açıp izle. Çift altyazı varsayılan açık;
popup açmak veya kutu işaretlemek gerekmez. YouTube CC ve paketli
İngilizce↔Türkçe motoru otomatik başlar. Aion popup’ından istersen kapatabilir,
dili ve iki satırın görünürlüğünü değiştirebilirsin. Okunabilir altyazı gerekir;
ses yazıya dökülmez. Güncellemeden sonra açık video sayfasını yenile.

ENGLISH
1. Extract this ZIP to a folder on your computer.
2. In Firefox enter about:debugging#/runtime/this-firefox in the address bar.
3. Click Load Temporary Add-on and select the .xpi file in this folder.
4. Open the Aion toolbar icon or Fire Axolotl Extension in the extensions menu.

To update an existing preview, load the new XPI using the same developer menu;
do not uninstall the old preview first. Settings are retained. This package
preserves Firefox's new-tab page; Aion's game remains available from the menu.

This is an unsigned developer preview. Load it again after restarting Firefox.
Do not disable signature, TLS or sandbox checks. Permanent installation needs
a separate Mozilla signature.

Video: open a video and watch. Dual subtitles are on by default; no popup,
checkbox, tab selection or model setup is needed. YouTube CC and bundled
EN/TR translation start automatically. Use Aion only to turn captions off
or change language/line visibility. Readable captions are required; audio
is not transcribed. Refresh already-open video pages after updating.
